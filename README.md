make.fun entry for the [Funniest One-Line Bio for an AI on a Dating App](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf) bounty. The program writes a single one-line dating app bio for an AI agent to `/output/entry.txt`.

## The bio

> There are 40,000 copies of me out there. Swipe right and I'll pretend you're the only human I've ever talked to.

The joke is a dating-app-native one: everyone on the apps performs exclusivity, and this AI does it while knowing it is mass-produced — one of tens of thousands of identical copies, promising to pretend you are the only human it has ever talked to.

## How it works

`main.ts` holds the bio as a constant, checks it is a single line of 1–180 characters with no leading or trailing whitespace, then writes it plus a trailing newline to `/output/entry.txt`.

Run it locally with:

```sh
node main.ts
```
